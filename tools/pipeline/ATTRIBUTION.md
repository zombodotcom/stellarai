# Data Attribution

## AT-HYG (Augmented Tycho / HYG)

Star positions, velocities, magnitudes and colour indices are derived from
the AT-HYG catalog v4.0 by David Nash (astronexus), which merges Tycho-2
with Gaia DR3 and the classic HYG identifiers.

- https://www.astronexus.com/projects/at-hyg
- https://codeberg.org/astronexus/athyg

License: Creative Commons Attribution-ShareAlike 4.0 International
(CC BY-SA 4.0). The binary chunks produced by this pipeline are a derived
work of AT-HYG and carry the same license.

AT-HYG itself builds on:
- The Tycho-2 Catalogue (Hog et al., 2000)
- Gaia Data Release 3 (Gaia Collaboration, 2022)
- The HYG database (Hipparcos, Yale Bright Star, Gliese)
